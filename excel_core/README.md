# excel_core — Lõi Excel dùng chung

Thư viện Python dùng chung cho Backend và Desktop:

- **Snapshot workbook:** mô hình dữ liệu chung (giá trị, công thức, định dạng, trang in, bộ lọc, biểu đồ).
- **Bộ đọc:** openpyxl (đọc file `.xlsx`, dùng ở Backend) và COM (đọc Excel đang chạy, dùng ở Desktop).
- **Diff:** so sánh file đề với file kết quả mẫu.
- **Kiểm tra điều kiện:** đánh giá điều kiện kiểm chứng của từng bước trong kịch bản.

**Được xây dựng ở:** GĐ4 (T4.1 – T4.5), bộ đọc COM ở T7.2.

# scripts — Công cụ quản lý repo và dữ liệu mẫu

| Script | Việc | Task |
|---|---|---|
| `create_issues.py` | Đọc bảng task trong `docs/quan-ly/ke-hoach-trien-khai.md`, tạo issue GitHub cho từng task | T0.6 |
| `import_lessons.py` | Chuẩn hóa bài học gốc của trung tâm vào `samples/_local/b<NN>-<mô-tả>/` | T1.2 |
| `build_solutions.py` | Tạo `dap-an.xlsx` cùng bố cục với đề bằng Excel thật (cần Excel trên máy) | T1.2 |
| `dump_workbook.py` | Xuất nội dung file Excel ra văn bản: giá trị, công thức, định dạng, trang in, **đề trong text box** | T1.2 – T1.4 |

Cách dùng chi tiết ghi ở đầu mỗi file. Quy trình tạo lại bộ bài mẫu: [docs/task/t1-3-ma-tran-ky-nang.md](../docs/task/t1-3-ma-tran-ky-nang.md#cách-tái-tạo-trên-máy-khác).

# samples — Bộ bài tập mẫu

Bài tập dùng để thiết kế, kiểm thử và thực nghiệm (T1.1 – T1.3). Quy tắc đặt tên: [dat-ten.md](../docs/quy-uoc/dat-ten.md#4-bài-tập-mẫu-samples).

```
samples/b09-du-lieu-dang-so/
├─ de.xlsx            file đề học viên nhận được
├─ dap-an.xlsx        file kết quả mẫu
├─ de-bai.pdf         đề bài (hoặc .docx)
├─ giao-trinh.pdf     chương giáo trình tương ứng (hoặc .docx)
└─ thong-tin.md       nguồn, nhóm kỹ năng, sheet nào là đề / đáp án, ghi chú
```

**Repo là public.** Chỉ đưa vào đây bài trung tâm đồng ý công khai hoặc bài nhóm tự soạn, đã xóa thông tin cá nhân. Bài chưa được phép đặt trong `samples/_local/` (không lên git).

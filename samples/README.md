# samples — Bộ bài tập mẫu

Bài tập thật từ trung tâm tin học, dùng để thiết kế, kiểm thử và thực nghiệm (T1.1 – T1.3).

## Quy ước

Mỗi bài một thư mục `samples/<mã-bài>/`, mã bài dạng `B01`, `B02`, …

```
samples/B01/
├─ de.xlsx          file đề (dữ liệu thô học viên nhận được)
├─ mau.xlsx         file kết quả mẫu của giảng viên
├─ de_bai.pdf       đề bài (hoặc .docx)
├─ giao_trinh.pdf   chương giáo trình tương ứng (hoặc .docx)
└─ info.md          nguồn, nhóm kỹ năng, ghi chú
```

Xóa thông tin cá nhân (tên, số điện thoại học viên…) trước khi đưa vào repo.

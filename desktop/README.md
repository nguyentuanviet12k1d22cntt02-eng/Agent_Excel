# desktop — Ứng dụng gia sư trên Windows (Python + PyQt6)

Bộ giám sát Excel (COM, Win32 API, MSAA, UI Automation), Teaching Agent chạy theo kịch bản đã duyệt, cửa sổ gia sư, mascot, overlay hướng dẫn. Desktop **không gọi AI**.

**Được xây dựng ở:** GĐ7 (T7.1 – T7.10).

## Cài môi trường

```powershell
py -3.14 -m venv desktop\.venv
desktop\.venv\Scripts\python -m pip install -r desktop\requirements.txt -r requirements-dev.txt
```

# spikes — Script làm thử kỹ thuật

Code thử nghiệm để trả lời câu hỏi "làm được không, làm thế nào" (GĐ0, GĐ2). **Không** dùng trực tiếp cho sản phẩm. Khi chuyển sang sản phẩm thì viết lại gọn trong `backend/`, `desktop/` hoặc `excel_core/`.

Mỗi spike một thư mục `spikes/<mã-task>_<tên>/`, có `README.md` ghi: mục tiêu, cách chạy, **kết quả và kết luận**.

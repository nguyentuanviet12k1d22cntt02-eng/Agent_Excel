# spikes — Code làm thử kỹ thuật

Code thử nghiệm để trả lời câu hỏi "làm được không, làm thế nào" (GĐ0, GĐ2). **Không** dùng trực tiếp cho sản phẩm. Khi chuyển sang sản phẩm thì viết lại gọn trong `apps/` hoặc `packages/`, đúng [quy tắc code](../docs/quy-uoc/quy-tac-code.md).

Mỗi spike một thư mục `spikes/t<gđ>-<số>-<mô-tả>/` (ví dụ `t2-4-uia-ribbon/`), có `README.md` ghi: mục tiêu, cách chạy, **kết quả và kết luận**.

# shared/schema — Lược đồ kịch bản hướng dẫn

JSON Schema của kịch bản hướng dẫn: "hợp đồng" chung giữa Web, Backend và Desktop.

- Tên file: `script.schema.json`, có trường phiên bản lược đồ.
- Mọi thay đổi lược đồ phải qua Pull Request có ít nhất 1 người phụ trách Backend và 1 người phụ trách Desktop duyệt.

**Được xây dựng ở:** T3.2.
